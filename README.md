## What I'm building

My main focus is **C# / .NET backend development**, databases and business-oriented
systems. I like understanding the process first, documenting the rules, and then
building the software around them.

- 🧩 Working with **C#, .NET, Blazor, EF Core, SQL and SQLite**.
- 🐧 Comfortable developing and deploying around **Linux, Docker and Git**.
- 🧠 Interested in backend architecture, APIs, data modeling and automation.
- 🎓 Studying **Systems Engineering** while building projects from real use cases.
- 🎛️ I also build tools and web experiences for audiovisual/live-production workflows.
